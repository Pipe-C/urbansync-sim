# UrbanSync Sim — backend dependencies
#
# Versions are pinned to what this project was actually built and tested against
# (Python 3.14, Windows). Every one of them resolves to a prebuilt wheel, so
# `pip install -r requirements.txt` needs no compiler.
#
# `passlib` is deliberately absent. AGENTS.md specified "passlib bcrypt", but
# passlib's last release was 2020 and it is incompatible with bcrypt 5: it reads
# `bcrypt.__about__.__version__` (removed in 4.1) and hands bcrypt a >72-byte
# probe hash, which bcrypt 5 rejects outright. The hashing is unchanged — the
# service calls `bcrypt` directly, which is the layer passlib was wrapping.
